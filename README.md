# sets-cards-game
A cross-platform card-matching game featuring 5 categories, card-passing mechanics, reflex-based SET! scoring, and persistent leaderboards. Playable on mobile and desktop!

"Sets: a Card Game", by  is a cross-platform card game built for mobile devices, laptops, and desktops. 

## 🎮 Features
- **5 Categories:** Cars, Fruits, Colors, Games, and Video Games (18 cards each).
- **Game Modes:** Single Player (vs AI), Offline (3 players on one device), and Online (up to 6 players).
- **Reflex 'SET!' Mechanic:** Press 'S' on your keyboard, right-click, or tap the button as fast as possible when someone gets 3 matching cards.
- **Scoring System:** Ranks from 1st (10,000 pts) down to 6th (0 pts).
- **Persistent Leaderboards:** Saves career totals locally using browser storage.
